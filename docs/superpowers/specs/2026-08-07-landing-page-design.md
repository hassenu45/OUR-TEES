# تصميم صفحة الهبوط — AZMA (index.html)

التاريخ: 2026-08-07
الحالة: معتمد من المستخدم

## الهدف

جعل صفحة الهبوط `index.html` احترافية وخالية من المحتوى الوهمي، مع ربطها ببيانات المتجر الحقيقية بحيث تظهر أي منتجات جديدة تُضاف من لوحة التحكم تلقائياً على الصفحة.

## النطاق

التغييرات محصورة في `index.html` + ملف سكربت جديد `js/landing.js`. لا تغيير على السيرفر (`server.js`) أو المتجر (`store.html`) أو لوحة التحكم (`admin.html`).

## القرارات المعتمدة

| النقطة | القرار |
|---|---|
| قسم "اللي لبسوا حكوا" (آراء وهمية) | حذفه نهائياً + CSS المرتبط به |
| قسم "أرقام بتتكلم" | إبقاؤه بأرقام حقيقية من المتجر (انظر أدناه) |
| قسم الدروب | ديناميكي: أحدث المنتجات المتاحة فقط (غير المباعة)، الأحدث أولاً |
| الهيرو | مربوط بالإعدادات: heroBadge / heroTitle / heroSubtitle / currencySymbol |
| بطاقة الهيرو | تعرض أحدث منتج متاح (صورة، اسم، سعر بعملة الإعدادات) |

## الأرقام الحقيقية لقسم "أرقام بتتكلم"

1. إجمالي المنتجات: عدد المنتجات الفعلي في المتجر
2. متاح الآن: عدد المنتجات غير المباعة (soldOut = false)
3. مقاسات متوفرة: عدد المقاسات من `settings.sizes`
4. شحن 24 ساعة: ادعاء خدمة حقيقي (ثابت — من FAQ المتجر)

يُحذف الرقم الوهمي "4.9/5 تقييم العملاء" نهائياً.

## التنفيذ الفني

1. في `index.html`:
   - إزالة قسم الآراء (testi-grid + CSS الخاص به)
   - تحويل قسم الأرقام إلى قيم تُملأ ديناميكياً (الاحتفاظ بالأنيميشن)
   - تفريغ حاوية قسم الدروب وإضافة `id="drops-grid"`
   - تفريغ بطاقة الهيرو وإضافة `id` للعناصر القابلة للتعبئة (الشارة، العنوان، الوصف، صورة البطاقة، الاسم، السعر)
   - إضافة `<script src="js/db-local.js">` و `<script src="js/api.js">` قبل سكربت landing
2. إنشاء `js/landing.js` يتبع نمط `js/store.js`:
   - `API.getSettings()` ثم `API.getProducts()`
   - عنوان الهيرو (`settings.heroTitle`) يُقسم لأسطر: 3 أسطر بأسلوب تقسيم الكلمات، السطر الأخير أصفر (مع الحفاظ على أنيميشن lineUp الحالي؛ حالات 1-2 سطر مدعومة)
   - عرض المنتجات: فلتر `soldOut !== true`، ترتيب تنازلي حسب `createdAt`
   - بطاقة المنتج: صورة (مع fallback أنيق عند غيابها)، الاسم، الوصف، السعر بصيغة العملة من الإعدادات، شارة البادج إن وجدت
   - الحالة الفارغة: رسالة أنيقة + زر "دخول المتجر" عند غياب منتجات متاحة
- شارة الهيرو: إن كانت `heroBadge` فارغة تُعرض القيمة الافتراضية "NEW DROP"
   - أرقام القسم تُملأ من البيانات الحقيقية
3. صيغة السعر: نفس تنسيق المتجر (`toFixed(2)` + رمز العملة)

## الحواف (Edge Cases)

- غياب صورة المنتج → placeholder مع لوجو العلامة
- `heroTitle` أقل من 3 كلمات → توزيع ذكي على سطر أو سطرين
- فشل API تماماً → fallback من `DB` (localStorage) عبر `js/api.js` الموجود؛ وإذا لم توجد بيانات أصلاً تظهر الحالة الفارغة
- منتجات كلها مباعة → الحالة الفارغة في قسم الدروب

## التحقق

- فتح `index.html` (مع `node server.js`): تظهر منتجات المتجر الحالية في الدروب وبطاقة الهيرو
- إضافة منتج من لوحة التحكم → يظهر على صفحة الهبوط عند التحديث (الأحدث أولاً)
- عدم ظهور أي أسماء أو أرقام مختلقة في الصفحة
