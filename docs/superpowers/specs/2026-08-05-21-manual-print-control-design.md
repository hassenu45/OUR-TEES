# Design: 21.html — Manual Print Control + Weak-Device Performance

تاريخ: 2026-08-05
النطاق: `21.html` فقط (موقع التيشيرت 3D Viewer)

## المشكلة

1. التحكم بالمطبوع يتم عبر لوحة CUSTOM PRINT (سلايدرز POS X/POS Y/ANGLE/SIZE + أزرار FRONT/BACK + Move/Tilt) — المستخدم يريد التحكم اليدوي المباشر على الصورة نفسها.
2. الأداء ثقيل على الأجهزة الضعيفة: 40K مثلث + ظلال 2048px + 4 مصادر إضاءة + إعادة بناء DecalGeometry كاملة عند كل حركة سحب.

## الحل المعتمد (بموافقة المستخدم)

### 1. إزالة لوحة CUSTOM PRINT بالكامل
- حذف عناصر اللوحة من HTML (`#printPanel` وما فيه من سلايدرز وأزرار) ومن CSS و JS.
- القيم الداخلية تبقى: `printSize`, `spinAngle`, `frontLocal`, `posOffsetX/Y`, `printSide`.

### 2. التحكم اليدوي المباشر
- **تحديد:** ضغطة/نقرة على الصورة (raycast على `printMesh`) → إطار أصفر متقطع حولها (Screen-space div يُحسب موضعه من إسقاط bbox للمطبوع) + زران عائمان.
- **تحريك:** سحب الصورة بإصبع واحد/ماوس → تحديث `frontLocal` عبر raycast على القميص، مع **عدم إعادة بناء الديكال أثناء السحب** (تحريك `printMesh.position` في العالم مباشرة بسرعة) وإعادة البناء مرة واحدة عند الإفلات.
- **تكبير:** عجلة الماوس فوق الصورة المحددة + قرصة بإصبعين (touch) → تحديث `printSize` مع إعادة بناء مبثوثة بـ rAF (مرة واحدة لكل فريم).
- **تدوير:** دوران بإصبعين (touch، زاوية المتجه بين الإصبعين) + Shift+سحب بالماوس (ديسكتوب) → تحديث `spinAngle` مع إعادة بناء مبثوثة.
- **زر عائم ⟳:** قلب الصورة Front/Back (`printSide` toggle + إعادة بناء).
- **زر عائم ✕:** حذف المطبوع (اختفاء الإطار والأزرار).
- **إلغاء التحديد:** ضغطة على مكان فاضي (raycast على القميص خارج الصورة) أو على خلفية.

### 3. الأداء (الوضع الضعيف)
- **كشف تلقائي:** `navigator.deviceMemory <= 4 || navigator.hardwareConcurrency <= 4 || isMobile` → weak mode.
- الوضع الضعيف: `renderer.setPixelRatio(1)` بدل `min(dpr,2)`، ظل 1024 بدل 2048 (أو إيقاف عند ذاكرة ≤2)، إضاءة مقلّصة (hemi + key فقط)، دخول فوري بدون أنيميشن gsap.
- **استراتيجية إعادة البناء:** أثناء التفاعل نعدّل `printMesh` مباشرة (position/rotation في العالم) أو نحدّث القيمة فقط مع `needsRebake` flag، و `rebakeIfNeeded()` يُنفذ مرة لكل فريم (rAF). عند `pointerup` → bake نهائي.
- إزالة `ground` shadow plane في الوضع الضعيف اختيارياً (تبقى للقوية).
- تحديث نص الـ hint ليعكس اللفتات الجديدة.

## الملفات المتأثرة
- `21.html` فقط.

## التحقق
- Playwright: رفع صورة → اختيار → سحب (يتحرك فوراً) → عجلة/قرصة (تكبير) → دوران → قلب → حذف.
- فحص pixels (preserveDrawingBuffer للتشخيص فقط) للتأكد من ظهور المطبوع وتحريكه.
- اختبار الوضع الضعيف بمحاكاة `deviceMemory`/`hardwareConcurrency`.
