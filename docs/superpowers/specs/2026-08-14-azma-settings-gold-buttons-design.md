# تصميم أزرار تطبيق "أعدادات أزما" — ذهبي فاخر + حركة قوية

التاريخ: 2026-08-14
الحالة: معتمد من المستخدم

## الهدف

إعادة تصميم جميع أزرار تطبيق الإعدادات (AZMA Settings / admin.html) بهوية ذهبية فاخرة مع حركات أنيميشن قوية، مع الحفاظ على الوظائف الحالية بالكامل.

## النطاق

- الملفات المصدرية (يتم نسخها إلى desktop/web عند البناء):
  - `admin.html` — نظام `.btn` المضمّن (inline style) + الأزرار الثابتة
  - `js/admin-animations.js` — طبقة GSAP للحركة
  - `js/admin.js` — الأزرار الديناميكية (لا تغيير في بنيتها، فقط تتأثر بالكلاسات)
  - `assets/css/design-tokens.css` — توكينات الألوان إن لزم
- خطوة البناء النهائية: `node desktop/scripts/build-web.mjs` لتحديث نسخة التطبيق

## التصميم

### 1. الأزرار الرئيسية (`.btn-accent`)

- تدرج ذهبي فاخر: من `#F5C842` إلى `#B8860B` تقريباً
- نص أسود داكن (`#0C0A09`) بدلاً من الأبيض الحالي — أناقة فاخرة
- ظل توهج ذهبي خارجي + ظل داخلي خفيف يمنح عمقاً
- شعاع لمعان (shine sweep) ينزلق عبر الزر عند hover
- نبضة توهج مستمرة لزر "حفظ جميع الإعدادات"
- موجة Ripple ذهبية عند النقر
- انضغاط عند الضغط: `scale(0.96)`

### 2. أزرار الإطار (`.btn-outline`)

- إطار ذهبي + نص ذهبي
- عند hover: توهج ذهبي ناعم + تعبئة ذهبية شفافة خفيفة
- نسخة light theme تبقى متوافقة (معادلة الألوان لـ `body.light`)

### 3. أزرار خاصة

- زر الدخول (password gate): نمط ذهبي فاخر كامل
- أزرار الإغلاق الدائرية (`.modal-close`): توهج ذهبي عند hover + دوران خفيف
- `.btn-danger`: يبقى أحمر لكن بتوهج أحمر فاخر أعمق
- عناصر sidebar (تحقق من التحديث): توهج ذهبي عند hover

### 4. الحركة (GSAP عبر admin-animations.js)

- دخول الأزرار داخل كل لوحة: ظهور متتالٍ (stagger) بحركة pop
- النقر: نبضة + توهج (يتم ربطه عبر delegation إن أمكن)
- حفظ ناجح: حركة فرح موجودة حالياً تُطوَّر (قفزة + توهج)
- احترام `prefers-reduced-motion`

## القيود

- لا تغيير في بنية HTML أو منطق JavaScript الوظيفي
- لا إضافة مكتبات جديدة — GSAP موجود محلياً
- التوافق مع الوضعين الداكن والفاتح
- عدم كسر الحركات الحالية في admin-animations.js
