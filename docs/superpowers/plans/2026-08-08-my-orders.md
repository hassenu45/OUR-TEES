# صفحة "طلباتي" (My Orders) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** إضافة صفحة طلبات للعميل على نمط تيمو — زر "إتمام الطلب" يوديه على `my-orders.html` حيث يعبي بياناته (وتُحفظ)، يختار الدفع، يشوف طلباته ويلغيها من نفس الصفحة.

**Architecture:** صفحة عامة `my-orders.html` + `js/my-orders.js` تقرأ السلة من localStorage وتتحدث مع السيرفر. السيرفر يحفظ بيانات العميل في جدول `Customer` جديد (upsert بالهاتف)، ويضيف حقل `paymentMethod` للطلب، ويكشف نقطتين عامتين: جلب بيانات/طلبات العميل بالهاتف، وإلغاء طلب مع التحقق من ملكية الهاتف والحالة.

**Tech Stack:** Express (server.js) + Prisma v7 (adapter libsql/pg) + zod + SQLite محلياً / PostgreSQL إنتاجاً + HTML/CSS/JS نقي (لا إطار عمل) + vitest.

## Global Constraints

- اللغة عربية RTL في كل الواجهات الجديدة. التصميم بنمط المواقع التجارية الحديثة (تبويبات، بطاقات، شارات حالة) على هوية AZMA (design-tokens: خلفية داكنة، ذهبي #A16207).
- `my-orders.html` و `js/my-orders.js` يجب ألا يُضافا إلى `ADMIN_ONLY_PAGES` ولا `PROTECTED_PAGES` في server.js.
- الدفع الإلكتروني **محاكاة فقط** — يُسجل `paymentMethod: 'card'` في قاعدة البيانات دون أي بوابة دفع. الافتراضي `cod`.
- نقاط API العامة الجديدة تُحمى بـ `rateLimit` (النمط الموجود في server.js).
- إلغاء الطلب: الحالة تصبح `cancelled` (لا حذف)، ويُسمح فقط عندما تكون الحالة `new` ومع تطابق رقم الهاتف.
- هيكل عنصر السلة في localStorage (مفتاح `azma_cart`): `{key, id, name, price, size, type, image, qty}`.
- لا تُلمس الملفات/السطور المتعلقة بـ ADMIN_ONLY_PAGES الحالية ولا الـ migrations الموجودة.

```js
// Pure business rules for the customer order flow (my-orders page)
function normalizePhone(phone) {
  return String(phone || '').replace(/[\s-]/g, '');
}

function isValidPhone(phone) {
  const p = normalizePhone(phone);
  return /^(\+?[0-9]{8,15})$/.test(p);
}

function canCancelOrder(order, phone) {
  if (!order) return { ok: false, error: 'الطلب غير موجود' };
  if (order.status !== 'new') {
    const label = order.status === 'completed' ? 'مكتمل' : order.status === 'cancelled' ? 'ملغي' : 'غير معروفة';
    return { ok: false, error: 'لا يمكن إلغاء هذا الطلب — حالته ' + label };
  }
  if (normalizePhone(order.phone) !== normalizePhone(phone)) {
    return { ok: false, error: 'رقم الهاتف لا يطابق صاحب الطلب' };
  }
  return { ok: true };
}

function composeAddress(details) {
  const parts = [details.city, details.area, details.street, details.landmark]
    .map((s) => String(s || '').trim())
    .filter(Boolean);
  return parts.join('، ');
}

module.exports = { normalizePhone, isValidPhone, canCancelOrder, composeAddress };
```

```js
async function upsertCustomer(data) {

    update: {
      name: data.name,
      city: data.city || '',
      area: data.area || '',

      notes: data.notes || '',

      name: data.name,
      city: data.city || '',
      area: data.area || '',
      street: data.street || '',
      landmark: data.landmark || '',
      notes: data.notes || '',
      totalOrders: 1,
```

```js
      productPrice: product.price,
      type: rest.type,
      size: rest.size,
      customerName: rest.customerName,

      notes: rest.notes,
      status: 'new',

      phone: rest.phone,
      name: rest.customerName,
      city: data.city,
      area: data.area,
      street: data.street,
      landmark: data.landmark,
      notes: rest.notes,
```

```js
    const check = canCancelOrder(order, phone);
    if (!check.ok) return res.status(400).json({ error: check.error });
    const updated = await db.updateOrderStatus(req.params.id, 'cancelled');
    res.json({ ok: true, order: updated });
  } catch (e) {
    console.error('cancel order error:', e.message);
    res.status(500).json({ error: 'خطأ في إلغاء الطلب' });
  }
});
```
