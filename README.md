# 🛒 AZMA — متجر تيشيرتات أونلاين

نظام متكامل لإدارة متجر ملابس (تيشيرتات) مع لوحة تحكم كاملة ومساعد ذكاء اصطناعي.

---

## 📋 الميزات الأساسية

### 🏪 المتجر (Store)
- عرض المنتجات مع صور متعددة
- تصنيف حسب النوع (قطن، فينتاج، بريميوم، oversized)
- اختيار المقاس (S, M, L, XL, XXL)
- زر طلب مباشر (Order Now) لكل منتج
- شارات (NEW, BESTSELLER, SOLD OUT)

### 🔐 لوحة التحكم (Admin Panel)
- دخول بكلمة مرور أو Google OAuth
- لوحة إحصائيات (عدد المنتجات، الطلبات، الإيرادات)
- إضافة منتج بالصور والوصف والسعر
- تعديل/حذف المنتجات
- عرض وإدارة الطلبات (جديد، مكتمل، ملغي)
- إعدادات الموقع (الاسم، العملة، المقاسات، الخامات)
- إعدادات الذكاء الاصطناعي

### 🤖 الذكاء الاصطناعي (Tez)
- بوت محادثة تفاعلي في المتجر
- يستخدم **DeepSeek AI** (أو أي بوابة OpenAI متوافقة عبر `.env`)
- يجاوب على أسئلة العملاء: الأسعار، المقاسات، الطلبات، الشحن
- اسم البوت وتوجيهاته قابلة للتعديل من لوحة التحكم

### 💾 قاعدة البيانات
- SQLite (محلياً) 
- PostgreSQL (للإنتاج)
- Prisma ORM للتعامل مع قاعدة البيانات

## 🚀 تشغيل المشروع محلياً

### المتطلبات
- Node.js (v18+)
- npm

### الخطوات

```bash
# 1. تثبيت الاعتماديات
npm install

# 2. توليد ملفات Prisma
npx prisma generate

# 3. تشغيل السيرفر
node server.js
```

⚠️ قبل التشغيل، تأكد من وجود ملف `.env`:

```
DATABASE_URL="file:./dev.db"
SESSION_SECRET="your-secret-key"
DEEPSEEK_API_KEY="sk-..."
DEEPSEEK_BASE_URL="https://api.deepseek.com"
DEEPSEEK_MODEL="deepseek-chat"
```

### الوصول للموقع
- المتجر: `http://localhost:3000/store.html`
- لوحة التحكم: `http://localhost:3000/login.html`
- باسورد الدخول الافتراضي: `admin123`

## 🔑 الـ API Endpoints

### المصادقة
| المسار | الطريقة | الوصف |
|--------|---------|-------|
| `/api/login` | POST | تسجيل الدخول |
| `/api/logout` | POST | تسجيل الخروج |
| `/api/auth/check` | GET | التحقق من الجلسة |
| `/api/auth/google` | POST | تسجيل Google |

### المنتجات
| المسار | الطريقة | الوصف |
|--------|---------|-------|
| `/api/products` | GET | عرض المنتجات |
| `/api/products` | POST | إضافة منتج |
| `/api/products/:id` | PUT | تحديث منتج |
| `/api/products/:id` | DELETE | حذف منتج |

### الطلبات
| المسار | الطريقة | الوصف |
|--------|---------|-------|
| `/api/orders` | GET | عرض الطلبات |
| `/api/orders` | POST | إنشاء طلب جديد |
| `/api/orders/:id/status` | PUT | تحديث حالة الطلب |

### الإعدادات
| المسار | الطريقة | الوصف |
|--------|---------|-------|
| `/api/settings` | GET | عرض الإعدادات |
| `/api/settings/admin` | GET | عرض الإعدادات الكاملة |
| `/api/settings` | PUT | حفظ الإعدادات |

### الذكاء الاصطناعي
| المسار | الطريقة | الوصف |
|--------|---------|-------|
| `/api/chat` | POST | إرسال رسالة للبوت (Tez) |
| `/api/ai/status` | GET | حالة إعداد الذكاء الاصطناعي |
| `/api/ai/generate-description` | POST | توليد وصف تسويقي لمنتج |
| `/api/ai/order-reply` | POST | اقتراح رد ذكي لطلب عميل |
